# DailyDiet v1 (legacy)

The original static SPA lives at the **repository root**:

- `index.html`, `src/main.ts`, `src/render.ts`, `src/storage.ts`, `src/types.ts`, `src/style.css`
- Data: `public/data/meal-plan.json` + browser `localStorage`

Run v1:

```bash
npm install   # root package.json
npm run dev
```

**v2 clients** use the Python API — see [`apps/web`](../web) and root [`README.md`](../../README.md).
